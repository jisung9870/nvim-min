# nvim-min 문서

## 현재 상태

nvim-min은 `NVIM_APPNAME`으로 기존 Neovim 설정과 분리해 실행하는 `vim.pack` 기반 구성이다.
문서는 `nvim-min` 브랜치의 커밋 `80d026b`를 기준으로 작성했으며, 아직 정식 Git 태그는 없다.

## 문서 원칙

- 코드와 다른 설명은 문서 결함으로 취급한다. 기능 변경과 문서 변경을 같은 PR에 포함한다.
- 확인되지 않은 성능 수치나 호환성은 보장처럼 기록하지 않는다.
- 키맵, 사용자 명령, 플러그인 목록은 각 Lua 모듈을 최종 근거로 삼는다.
- 배포된 변경만 버전 섹션으로 옮기고, 배포 전 변경은 `Unreleased`에 유지한다.

## 빠른 경로

처음 설치한다면 [빠른 시작](getting-started.md)부터 진행한다. 일상적인 플러그인 업데이트나
복구가 목적이라면 [운영과 유지보수](operations.md)를 바로 확인한다.
